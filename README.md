This is a powerful and user-friendly QR Code Generator built using Python (Tkinter) and Pillow, with features like:

✅ Full-screen GUI
✅ Logo embedding inside QR
✅ Export QR as PNG and PDF
✅ Dark/Light Theme Toggle

🔧 Features
  Simple Input: Enter text or URL to generate a QR code instantly
  Logo Support: Add your brand or logo to the center of the QR
  Full-Screen Mode: Clean, distraction-free interface
  Dark/Light Theme Switch: Toggle themes with a single click
  Save & Export: Save QR as image + auto-generate a PDF with QR and content
